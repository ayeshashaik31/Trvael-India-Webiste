# ✈️ Travel India

A responsive travel website built using HTML, CSS, and JavaScript.  
Travel India allows users to explore travel packages, view destinations, submit booking details, and contact the travel team.

## 🌟 Features

- 🏠 Home section with Explore Now button
- 📦 Travel packages
- 📝 Booking form
- 📞 Contact form
- ⭐ Customer reviews
- 🖼️ Travel gallery
- 🛎️ Travel services section
- 📱 Responsive design for desktop, tablet, and mobile
- 🔄 Smooth scrolling navigation
- 🎯 Interactive buttons using JavaScript
- 💬 Booking and contact success alerts

## 🗺️ Available Packages

- Goa
- Manali Adventure
- Rajasthan Heritage
- Kerala Paradise
- Kashmir Delight

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
